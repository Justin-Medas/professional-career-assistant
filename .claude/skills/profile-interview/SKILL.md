# Profile Interview

Follows `playbooks/interviewing.md` and `playbooks/question-bank.md`.

1. Read `profile/open-questions.md`. Select 3 to 5 questions: those blocking an active job first, then highest impact. Keep quick "confirm this old fact" items separate from "tell me something new."
2. One idea per question. Ask for evidence: numbers, dates, before and after, who was affected, what it enabled next.
3. If the user does not know a number, record the accomplishment without one. Never invent.
4. After each answer run `self-heal`: update the canonical file, remove the resolved question, log it.
5. Close with what changed and what remains open.
