# Templates

Blank starter files. Setup (`playbooks/onboarding.md`, Step 0) copies them into the real, git-ignored locations the first time a workspace is used. Edit the copies, never these.

| Template | Copied to |
|---|---|
| `profile/*` | `profile/` |
| `reference/interview-answers.md` | `reference/interview-answers.md` |

Why: this repository is public and shared. Everything about a real person (career history, jobs, answers, overrides) lives only in git-ignored paths on that person's machine, so improvements to the shared playbooks, skills, and templates can be committed without ever including personal data.
